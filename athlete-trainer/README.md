# 运动员训练管理系统（Athlete OS · Sprint & Jump）

面向田径短跑 / 跳跃运动员的个人训练与身体监控系统。所有功能均为**纯本地网页应用**，数据保存在浏览器 localStorage，可离线使用，不经过任何服务器。

## 功能

## 快速开始

### 方式 A：直接打开（最简单）

双击 `index.html` 即可使用。部分浏览器对 `file://` 下的 localStorage 有策略差异，建议用方式 B 获得最一致的体验。

### 方式 B：本地服务（推荐）

macOS 双击 `start.command`，或终端执行：

```bash
cd 本目录
python3 -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765
```

### 方式 C：部署

将整个 `athlete-trainer` 文件夹上传到任意静态托管（GitHub Pages、Netlify、Vercel、自有服务器均可），无需后端。换设备时在旧设备「数据管理 → 下载备份」，新设备打开后「导入备份」。

## 数据与隐私

- 数据只保存在当前浏览器，可通过「数据管理」随时下载 JSON 备份。
- 建议每次重要更新后下载一次备份；清空 / 载入示例数据前也请先备份。
- 首次打开时数据完全为空，只保留一位空白运动员档案，所有记录均由用户自己录入；如需预览界面效果，可在「数据管理」中手动载入示例数据。

## 分析算法说明

### 力速曲线（加速 F-v 剖面）

录入一次 30–60 m 冲刺中多个标记点的累计时间后，采用单指数速度模型拟合：

```
d(t) = Vmax · [t + τ(e^(-t/τ) − 1)]
a(v) = (Vmax − v) / τ，F = m·a
Pmax = m·a0·Vmax / 4
```

输出理论最大速度 V0、理论最大加速度 a0（等价相对力量 F0/kg）、最大功率 Pmax、标准化力速斜率与剖面类型。当前实现采用忽略空气阻力的常用简化，标注于分析页。拟合要求至少 4 个有效分段时间，R² < 0.85 会提示检查计时数据。

### RSI（反应力量指数）

跳深测试中：

```
跳起高度 JH = g·Tf² / 8   （Tf 为腾空时间）
RSI = JH / 触地时间
```

录入每次试跳的跳深高度、腾空时间与触地时间即可，界面中的分级（<1.5 / 1.5–2.0 / 2.0–2.5 / >2.5）为通用参考，实际还应结合跳深高度与运动员水平解读。

## 说明与限制

- 支持多运动员管理；所有页面与 PDF 报告都只展示“当前运动员”的数据，可在左侧底部下拉框或「运动员管理」页快速切换。
- 支持中英文界面切换，语言偏好保存在浏览器本地；中英文切换不影响任何已录入数据。
- 字段与内容格式参考了附件中的短跑训练表风格，但为通用录入设计，不依赖原始 Excel。
- 静息心率预警、RSI 分级等仅为辅助提示，不构成医疗建议；持续异常请咨询队医 / 医生。
